Projeto criado para exibir as notificações de um iphone no ios 26 em um  Tenstar t-display ESP32-D0WD

Tela de boot: royal enfield meteor 350cc

Exibe notificações de:
instagram
whatsapp
sms
chamadas
mídia em execução

Em standby exibe gifs animados

Bibliotecas utilizadas:
TFT_eSPI 2.5.43
NimBLE-Arduino 5.5.1
AnimatedGIF 2.2.0
LittleFS 1.6.3

Arquivos de animação (.gif) enviados via plugin arduino-littlefs-upload-1.6.3.vsix
